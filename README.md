# Natural Language over Code: Deterministic Prompt Engineering

> *“Syntax decays, logic compounds.”*

`logic-compounds` is a framework that reframes prompt engineering from unstructured conversational prose into deterministic software architecture. By treating the LLM context window as an auto-regressive state machine, this repository establishes strict linguistic constraints, text boundaries, and string invariants to govern complex model reasoning.

---

## Architecture: The 5-Tier Structural Trajectory

The framework operates on a rigid cascading progression matrix:

1. **Tier 1: Epistemic & Attentional Gating** — Establishes strict epistemic boundaries and filters noise before reasoning sequences initiate.
2. **Tier 2: Structural Decomposition** — Deconstructs complex objectives into isolated syntactic units using schema models and EBNF/GBNF grammar matrices.
3. **Tier 3: Non-Linear Latent Space Search** — Orchestrates exploratory prompt paths and multi-threaded reasoning frameworks (e.g., Tree-of-Thoughts, Skeleton-of-Thought).
4. **Tier 4: Reflexive Verification** — Deploys self-consistency loops and logical consistency checks to validate generated artifacts.
5. **Tier 5: Dynamic Execution & Bounded Lifecycles** — Governs state-machine handoffs, persistence, and cleanup protocols across multi-turn sessions.

## Context-Bounded Safeguards

When working with or migrating prompt repositories based on this framework, standard global search-and-replace scripts must be avoided. Modifying files without context awareness risks corrupting literal token blocks, ASCII dependency trees, schema models, and GBNF grammar definitions. Use context-bounded parsing methods to ensure invariants remain uncompromised.
